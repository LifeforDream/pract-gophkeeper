# `logout`

Удаляет локальный файл сессии и локальный кэш.

```
gophkeeper [глобальные опции] logout
```

Не принимает опций и аргументов (кроме `-h`). Работает локально и к серверу не обращается: токен на сервере
не отзывается и остаётся действительным до истечения срока, поэтому `logout` защищает только от того, что
кто-то позже прочитает файлы на этом компьютере.

Вместе с сессией удаляется кэш: файл `cache.json` и каталог `bodies/` рядом с файлом сессии (см.
[«Локальный кэш»](README.md#локальный-кэш)). Если удалить не удалось что-то одно, команда всё равно пытается
удалить второе и сообщает об ошибке.

После `logout` любая команда работы с хранилищем завершается ошибкой `unauthenticated, run login`, пока вы
не выполните [`login`](login.md) снова. Ваши секреты остаются на сервере.

Если вы используете нестандартный файл сессии, укажите тот же `-session`, что и при входе: кэш лежит рядом
с ним и удаляется вместе с ним.

См. также: [`login`](login.md).
