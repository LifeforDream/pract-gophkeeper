# `logout`

Удаляет локальный файл сессии.

```
gophkeeper [глобальные опции] logout
```

Не принимает опций и аргументов (кроме `-h`). Работает локально и к серверу не обращается: токен на сервере
не отзывается и остаётся действительным до истечения срока, поэтому `logout` защищает только от того, что
кто-то позже прочитает файл на этом компьютере.

После `logout` любая команда работы с хранилищем завершается ошибкой `unauthenticated, run login`, пока вы
не выполните [`login`](login.md) снова. Ваши секреты остаются на сервере.

Если вы используете нестандартный файл сессии, укажите тот же `-session`, что и при входе.

См. также: [`login`](login.md).
