# `login`

Выполняет вход в существующий аккаунт и сохраняет локальную сессию.

```
gophkeeper [глобальные опции] login [--login <логин>]
```

## Опции

| Флаг | По умолчанию | Значение |
|---|---|---|
| `--login` | *(запрос)* | Логин аккаунта |

## Поведение

1. Берёт логин из `--login` или запрашивает `Login:`. Если stdin — не терминал, `--login` **обязателен**.
2. Берёт пароль из `GOPHKEEPER_PASSWORD` или запрашивает `Password:` (без отображения символов, один раз).
3. Получает с сервера параметры вывода ключей, выводит ключи локально и проходит аутентификацию.
4. Перезаписывает файл сессии (см. [файл сессии](README.md#файл-сессии)).

Выполняйте команду, когда сессия истекла (по умолчанию через 24 часа), когда меняете `-a`/`-session` или на
новой машине.

Если такого логина нет, сервер отвечает так же, как при неверном пароле, поэтому неудачный вход не
раскрывает, существует ли аккаунт.

## Примеры

```sh
gophkeeper login --login alice
GOPHKEEPER_PASSWORD="$(pass show gophkeeper)" gophkeeper login --login alice
```

## Ошибки

- `login or password is incorrect, try again` (код 1).
- `--login is required when stdin is not a terminal` (код 2).

См. также: [`register`](register.md), [`logout`](logout.md).
