# `version`

Печатает версию клиента.

```
gophkeeper version
```

Клиент печатает сведения о сборке самым первым действием при *любом* запуске:

```
Build version: v0.1.0
Build date: 2026-11-04
```

поэтому самой команде `version` больше делать нечего. Если бинарник собран без флагов сборки, оба значения
равны `N/A`. К серверу команда не обращается.
