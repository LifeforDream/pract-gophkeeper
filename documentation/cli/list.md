# `list`

Показывает все ваши секреты без их содержимого.

```
gophkeeper [глобальные опции] list [--offline] [--type <тип>] [--meta-key <ключ>] [--name <фрагмент>]
```

Сначала команда синхронизирует локальный кэш с сервером (запрашивает только изменения с последней ревизии),
затем фильтрует и выводит записи из кэша.

## Опции

| Флаг | По умолчанию | Значение |
|---|---|---|
| `--type <тип>` | *(любой)* | Только секреты этого типа: `login`, `text`, `binary`, `card` |
| `--meta-key <ключ>` | *(любой)* | Только секреты, у которых есть такой ключ метаданных (точное совпадение, с учётом регистра). По значению метаданных фильтрации нет. |
| `--name <фрагмент>` | *(любой)* | Только секреты, в имени которых есть этот текст (без учёта регистра) |
| `--offline` | выкл. | Не обращаться к серверу, читать только кэш |

Заданные фильтры объединяются по И. Позиционные аргументы не принимаются.

Вывод (stdout):

```
Found Items:
1. id: 6f1c0b1e-… | name: github | type: login | version: 2
2. id: 0a77d2f4-… | name: ssh-key | type: binary | version: 1
```

`version` увеличивается при каждом обновлении и служит для обнаружения одновременных правок. Удалённые
секреты в списке не показываются.

Выводятся только имена, типы и id; содержимое и метаданные смотрите через [`get`](get.md).

## Работа без сервера

Если сервер недоступен (`UNAVAILABLE` или таймаут), `list` показывает последние сохранённые данные и
печатает в stderr предупреждение `warning: server is unreachable, showing cached data`; код выхода 0.
С `--offline` сервер не опрашивается вообще, предупреждение: `warning: offline mode, showing cached data`.
В этом режиме не требуется неистёкший токен, но нужна сессия (`login`).

Данные из кэша могут быть устаревшими. Другие ошибки (истёкший токен, ошибки TLS и т. п.) кэшем не
маскируются. Если в кэше ещё ничего нет, список будет пустым.

Записи, созданные или изменённые этим клиентом после последней синхронизации, при работе без сервера
показываются в конце списка.

## Ошибки

- `unauthenticated, run login` / `session expired, run login` (не относится к `--offline`: срок токена не проверяется).
- `unknown secret type: X` — недопустимое значение `--type` (код 2).
- `unexpected argument "X", use --name to filter by name` (код 2).
