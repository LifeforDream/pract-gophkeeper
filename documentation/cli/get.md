# `get`

Показывает один секрет.

```
gophkeeper [глобальные опции] get [--show] [--out <файл> [--force]] <id|name>
```

Опции должны идти **перед** `<id|name>`: парсер флагов Go останавливается на первом аргументе, не
являющемся флагом, поэтому `get github --show` отклоняется с ошибкой `invalid reference`.

## Опции

| Флаг | По умолчанию | Значение |
|---|---|---|
| `--show` | выкл. | Печатать чувствительные поля открытым текстом |
| `--out <файл>` | *(нет)* | Только для `binary`: записать содержимое в этот файл |
| `--force` | выкл. | Вместе с `--out`: перезаписать файл, если он существует |

## Вывод

Первые две строки одинаковы для всех типов:

```
Secret id: <uuid>, name: <name>, type: <type>, version: <n>
Secret meta: "k=v k2=v2"
```

далее, по типам:

| Тип | Строки | Маскирование без `--show` |
|---|---|---|
| `login` | `Login:`, `Password:` | пароль выводится как `********` |
| `text` | `Text:` | нет |
| `binary` | `File name:`, `File size:` (в байтах) — или, с `--out`, `Wrote secret to file: <путь>` | нет |
| `card` | `Card Number:`, `Card Holder:`, `Card Expiry:`, `Card CVV:` | номер как `1234****5678` (только `*`, если короче 16 цифр), CVV как `***` |

## Бинарные секреты

Без `--out` печатаются только имя и размер файла, ничего не записывается. С `--out`:

- файл создаётся с правами `0600`;
- если он уже существует, команда завершается ошибкой `file already exists`, кроме случая с `--force`:
  тогда файл усекается и перезаписывается.

`--show` на бинарные секреты не влияет.

## Примеры

```sh
gophkeeper get github
gophkeeper get --show github
gophkeeper get --show 6f1c0b1e-0000-0000-0000-000000000000
gophkeeper get --out id_ed25519 --force ssh-key
```

## Ошибки

- `record not found` (код 1).
- `id or name X returned multiple values: [...]` — используйте id (код 1).
- `invalid reference` — позиционных аргументов не ровно один (код 2).
- `file already exists` (код 2).

См. также: [`list`](list.md).
