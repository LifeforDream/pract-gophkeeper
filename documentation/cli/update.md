# `update`

Изменяет секрет. Команда интерактивная: показывает текущие значения как значения по умолчанию и спрашивает
новые.

```
gophkeeper [глобальные опции] update <id|name>
```

Опций, кроме `-h`, нет.

## Ход работы

1. Получает секрет (ошибки `record not found` и неоднозначности — как у [`get`](get.md)).
2. По очереди задаёт вопросы. **Пустой ответ оставляет текущее значение** в любом из них.

| Шаг | Запрос | Примечания |
|---|---|---|
| 1 | `Name (default …)` | |
| 2 | `Meta in the form of foo=bar baz=qux (default …)` | См. ниже |
| 3 | Поля типа | см. таблицу ниже |

| Тип | Поля |
|---|---|
| `login` | `New login`, `Password` (скрытый) |
| `text` | `Enter next text` (текущий текст показывается) |
| `binary` | `Enter path to file` — пустой ответ оставляет сохранённый файл |
| `card` | `Enter new card number` (скрытый, текущий показывается маскированным), `holder`, `expiry date`, `CVV` (скрытый) |

3. Отправляет новую версию. При успехе: `successfully updated record <id>`.

Тип секрета изменить нельзя.

### Метаданные

Если на запрос метаданных ввести что-либо, это **заменяет все** существующие пары (слияния нет); ввод
делится по пробелам: `url=example.com note=work`. Из-за этого значения в `update` не могут содержать
пробелов. Некорректная пара (`foo` без `=`) прерывает команду. Удалить все метаданные сейчас можно только
удалением и повторным добавлением секрета.

## Одновременные правки

Обновление отправляется вместе с версией, которую вы прочитали. Если другой клиент тем временем изменил
секрет, сервер отклоняет запрос с ошибкой `record version is too old, please refresh` (код 1). Запустите
`update` ещё раз — он получит новую версию.

## Пример

```
$ gophkeeper update github
What would you like to change?
Name (default github):
Meta in the form of foo=bar baz=qux  (default "url=https://github.com"):
New login (default alice):
Password: (empty = keep previous)
successfully updated record 6f1c0b1e-…
```

См. также: [`get`](get.md), [`delete`](delete.md).
